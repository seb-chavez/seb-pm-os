# Goals Archive

Past quarterly goals files, named by quarter: `GOALS-2026-Q2.md`, `GOALS-2026-Q3.md`, etc.

The active quarter always lives at the repo root as `GOALS.md`. At the end of a quarter (or during a job transition), move it here with the appropriate suffix.

Both the root `GOALS.md` and everything in this folder are gitignored — quarterly goals are treated as sensitive and stay local-only.
