# Writing Style

Prose defaults for documents and chat replies. Use with `memory/doc-formatting.md` (Notion/Markdown structure) and `memory/prd-writing.md` (PRD section rules).

## Core rule

Write like a message to one person, not a stage speech. Brevity over completeness. If a sentence doesn't carry meaning, cut it.

## Cut on sight

### Importance sentences

Delete any sentence about impact, legacy, significance, or broader trends. State what happened, what breaks, or what to do.

### AI vocabulary

Don't use: pivotal, crucial, enhance, underscore, landscape, vibrant, testament, foster, delve, showcase, intricate, evolving, and similar filler.

### Contrast structures

No "It's not X, it's Y."
No "Not A. Not B. But C."
No "Despite this..."

### Vague authority

No "experts say," "industry reports," "many believe." Name the source or cut the claim.

### Summary endings

No "In conclusion," "Overall," or neat wrap-ups. Stop when the point is made.

## Replace or cut

### General claims

If it says "improves results," say how. If there's no proof, cut the line.

### Generic sentences

If a sentence could apply to 1,000 other topics, delete it.

### Long sentences

Shorten anything over 16 words. Split or cut.

## Tone

No motivational tone. No TED Talk energy. No preaching.

## When editing existing prose

Return the clean version only. No explanation, no meta commentary, no decorative formatting.
