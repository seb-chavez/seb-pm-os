# Public Context

Publicly available information relevant to current or upcoming roles — e.g., materials shared by a future EM, company blog posts, public docs.

This folder is **default-deny**: anything you drop in here is gitignored unless explicitly allowlisted in `.gitignore`. To track a new public file, confirm it contains no confidential information and run `git add -f <file>`, then add a `!<file>` line to `.gitignore` so future changes are picked up automatically.
