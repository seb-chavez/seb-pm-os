# People

Stakeholder dossiers — communication preferences, working styles, relationships, and context for key people you work with. This is where real compounding happens. The more context you capture, the better Claude can help you navigate stakeholder dynamics.

## Usage

Create one file per person: `firstname-lastname.md`

## Template

```markdown
# First Last - Role Title
- Reports to: Manager Name
- Cares about: What matters most to them (e.g., user research, shipping speed, cost)
- Communication style: How they prefer to receive information
- Pet peeve: What to avoid

## Recent context
- Current priorities, pushbacks, or sentiments
- Reactions to recent work or decisions
- Anything that affects how you engage with them right now

## Meeting notes
### [Date] - [Meeting topic]
- Key points discussed
- Their reactions or concerns
- Action items (especially what you owe them)
```

## Example

```markdown
# Sarah Kim - Design Lead
- Reports to: VP Design
- Cares about: User research, accessibility, craft
- Communication style: Visual thinker. Wants mockups, not docs.
- Pet peeve: Decisions made without user data

## Recent context
- Pushing back on the auth redesign timeline
- Concerned about mobile accessibility
- Liked the competitive analysis I shared last week

## Meeting notes
### March 21 - Auth redesign sync
- Wants mobile prototypes before eng sprint
- Asked for usability report from last iteration
- Action: I owe her the report by Friday
```

## Tips
- Update after every meaningful interaction — even a quick Slack thread
- Capture tone and sentiment, not just facts
- Note what you owe people and what they owe you
- The "Recent context" section is the most valuable — keep it current
